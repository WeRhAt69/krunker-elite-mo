- **Multiple targets:** Head, Body, Center
- **Adjustable FOV** (detection radius)
- **Right-click mode:** activate only when right-clicking

### 👁️ ESP (Visuals)
- **Player boxes** around enemies
- **Connecting lines** to players
- **Wireframe mode** (see through walls)
- **Chams** (colored highlights for allies/enemies)

- **TriggerBot:** automatic fire when aiming at enemy

### 🎮 Interface
- **Expandable Control Panel** (key O)
- **Help Panel** with all keybinds (key H)
- **Visual notifications** when toggling settings
- **FPS and player count** display
